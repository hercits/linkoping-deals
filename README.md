# 林雪平超市特价

林雪平 12 家超市的本周特价，按到 Vallastaden 的距离排列。网站：https://hercits.github.io/linkoping-deals/

- 优惠和商品图片来自 [Matpriskollen](https://matpriskollen.se)，每天早上自动更新 `data.json`
- 地图坐标来自 OpenStreetMap（`geo.json`，由 GitHub Actions 里的 `tools/geocode.py` 生成）
- 页面源文件在 `src/`，运行 `python3 tools/make_page.py` 生成 `index.html`
